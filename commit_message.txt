fix: improve robustness of auto-improve prompt XML tag extraction

Handle cases where LLMs output reasoning mixed with the final answer,
potentially emitting multiple <improved_prompt> tags or failing to close
the tag entirely.

- Use re.findall() and take the last match to prefer the final polished
  version when multiple <improved_prompt> blocks are present.
- Add fallback to extract text after the last <improved_prompt> open tag
  when no closing tag is found, preventing malformed output from leaking
  reasoning text into the main chat context.
